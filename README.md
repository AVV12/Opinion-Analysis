# Opinion-Analysis

### 1. Resume

Based on opinions from a workplace climate survey, we extract topics, message intentions, and sentiments using Transformers in Python. Subsequently, the results are presented in a Power BI dashboard for the client.

### 2. Database

The database comes from an annual workplace climate survey conducted in a company. These opinions are expressed openly.

### 3. Analysis

Transformers such as Helsinki-NLP and/or BERTopic have been primarily applied. To a lesser extent, LDA from Gensim has been used.
